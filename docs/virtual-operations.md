# 가상 장비 운영 데이터

등록된 83개 장비를 기존 ID·유형에 연결한다. 실제 제조사 사양이나 수집된 계측값이 아닌 시뮬레이션이다. AI 운영 요원은 기존 전용 화면을 유지한다.

| 유형 | 운영 지표 | 단위 |
| --- | --- | --- |
| 서버 랙 | CPU 사용률, 메모리 사용/총량, 디스크 사용/총량, 가동 상태 | %, GiB, TiB |
| 스토리지 랙 | 총용량, 사용률, 읽기/쓰기 처리량 | TiB, %, MiB/s |
| 네트워크 장비 | 정상/전체 포트, 수신/송신 트래픽, 링크 연결 | 개, Mbps |
| GPU 랙 | GPU 사용률, VRAM 사용/총량, 칩 온도, GPU 할당 | %, GiB, °C, GPU |
| GPU 호스팅 가상 AI 서비스 | 가상 모델명, 추론 상태, 처리 요청량 | 건/분 |
| 시설 장비 | 상대 습도, 누적 전력량, 가동 상태 | %, kWh |
| UPS / 배터리 | UPS 부하 / 배터리 잔량 | % |
| 냉각 장비 | 냉각 효율(COP), 냉각수 유량 | 무차원, L/min |
| 보안·관제·지원 장비 | 가동 상태, 누적 전력량 | kWh |

## 갱신·장애 연동

- 공통 레이아웃에서 2초마다 시뮬레이션 시간을 증가시킨다. 페이지 전환으로 시간을 초기화하거나 타이머를 중복 생성하지 않는다.
- ID를 이용한 결정적 파형으로 동일 장비·시각·장애 상태에서는 같은 수치를 생성한다. 용량·포트 수·GPU 수는 유지하고 사용량만 변한다.
- 기존 사고 선택기를 함께 사용해 주요 설비 장애와 연관 설비 주의를 반영한다. GPU 과열은 칩 온도 상승, GPU 할당 제한, 추론 지연으로 이어진다. 서버 전원 장애는 가동 중지, 네트워크 장애는 링크 단절, 스토리지 장애는 처리량 저하, 냉각 장애는 COP·유량 저하로 표시한다.
- 장애 종료 시 같은 시각의 정상 수치로 복구한다. 적산된 전력량은 보존한다.
- 누적 전력량은 각 2초 구간의 중간 시점 소비 전력(kW) × 경과 시간(h)을 합산한다. 전체 시뮬레이션 초기화 시에만 0으로 돌아간다.
- GPU 칩 온도는 기존 장비/흡기 온도와 다른 가상 센서다. 메모리·디스크는 이진 단위, 네트워크는 십진 비트 단위를 사용한다.
- PUE·분류별 전력·설비 상세는 같은 시뮬레이션 시각의 kW 값을 사용한다. 기존 PUE는 순간 소비 전력 비율인 가상 추정값이며 누적 에너지 PUE와 구분한다.

## 표시

- 디지털 트윈 우측 패널: 해당 유형의 주요 운영 지표 3개.
- 3D 장비 상세 모달 및 시나리오 제어: 전체 운영 지표와 GPU의 가상 AI 서비스.
- 모든 운영 지표 영역에 가상 데이터임과 갱신 주기를 표시한다. 새 아이콘이나 수동 갱신 버튼은 추가하지 않는다.
